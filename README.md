# 002couple · 볼떵이와 볼빵이

픽셀 아트 사이드 스크롤러. 볼떵이가 볼빵이에게 가는 한 스테이지.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 을 엽니다.

## 조작

- PC: ← → 이동, Z / Space / ↑ 점프, R 재시작
- 모바일: 화면 하단 터치 패드

## 개발 테스트

타이틀의 **엔딩 근처에서 시작 (테스트)** 로 엔딩 시퀀스를 바로 확인할 수 있습니다.
일반 **시작하기** 는 항상 고속터미널 정상 시작점입니다.

## 에셋

`public/assets/manifest.json` 에 UUID → 파일명 매핑이 있습니다.
원본 PNG는 Project store `internal/assets/` 에서 복사했습니다.
